🔑 רישום מסירת מפתחות
=====================================
הבנדאי בלובי רושם כל פעם שמישהו לוקח מפתח!

📝 בלובי (index.html):
- כרטיס "🔑 מפתחות משרדים"
- לחץ "➕ רישום מסירת מפתח חדש"
- מלא:
  * תאריך
  * קומה
  * יחידה
  * שם מלא
  * מספר טלפון
  * שעת קבלת מפתח
  * שעת החזרת מפתח (אופציונלי)
  * הערות (אופציונלי)
- לחץ "שמור" → נשמר ב-Firebase

🔐 באדמין (admin.html):
- טאב "🔑 מפתחות"
- רואה את כל הרישומים
- טבלה מסודרת עם כל הפרטים
- קריאה בלבד

📢 עדכונים למשמרת:
- כל הודעה = בלון נפרד
- אם יש 2 הודעות → 2 בלונים
- אם מוסיפים שלישית → 3 בלונים

הכל מוכן!
