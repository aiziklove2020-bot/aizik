🔐 הרשאות מנהלים - עובד!
=====================================
✅ רק מנהלים מורשים יכולים להיכנס
✅ הוסף/הסר מנהלים דרך המערכת
✅ אם מישהו לא ברשימה → לא נכנס!

👤 ניהול מנהלים:
1. התחבר כמנהל קיים
2. admin.html → "👤 ניהול מנהלים"
3. ➕ הוסף מנהל:
   - אימייל
   - שם מלא
   - סיסמה
4. שמור → המנהל החדש יכול להיכנס!
5. 🗑 מחק מנהל → לא יוכל יותר להיכנס

🔒 אבטחה:
- כל התחברות נבדקת מול רשימת המנהלים
- אם לא ברשימה → "אין לך הרשאות גישה"
- כל המנהלים שמורים ב-Firebase collection 'admins'
